# ⚡ fitจัง by พี่ต้นฮาร์ต พี่ต้นบุญ - แอปพลิเคชันคำนวณแคลอรี สัดส่วนสารอาหาร & วงล้อสุ่มออกกำลังกาย

เว็บแอปพลิเคชันเพื่อการดูแลสุขภาพและควบคุมน้ำหนักแบบครบวงจร (Fitness & Nutrition Tracker) พัฒนาขึ้นด้วย HTML5, CSS3 และ Pure JavaScript (Zero external dependencies) รองรับทั้งการเปิดใช้งานบนเว็บเบราว์เซอร์ และการรันเป็น Local Server

---

## 🚀 วิธีเปิดใช้งาน (Getting Started)

คุณสามารถเปิดใช้งานได้ง่ายๆ 2 วิธี:

### วิธีที่ 1: ดับเบิลคลิกเปิดใช้งานทันที (แนะนำ)
- ดับเบิลคลิกที่ไฟล์ `run_app.bat` หรือดับเบิลคลิกที่ `index.html` เพื่อเปิดใช้งานบนเว็บเบราว์เซอร์ (Chrome, Edge, Safari ฯลฯ) ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่ม

### วิธีที่ 2: รันผ่าน Local Server
- เปิด Terminal หรือ PowerShell ในโฟลเดอร์นี้ แล้วสั่งรัน:
  ```bash
  agy-node server.js
  ```
- จากนั้นเปิดเว็บเบราว์เซอร์ไปที่: `http://localhost:3000`

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. 👤 ข้อมูลร่างกาย & คำนวณความต้องการพลังงาน (Profile & BMI/TDEE)
- กรอก **เพศ, อายุ, น้ำหนัก (กก.), ส่วนสูง (ซม.), ระดับกิจกรรม และเป้าหมายสุขภาพ**
- คำนวณ **BMI (ดัชนีมวลกาย)** พร้อมแถบสีเกณฑ์มาตรฐานเอเชีย (WHO Asian Criteria) และคำนวณช่วงน้ำหนักตัวที่เหมาะสม (Ideal Weight)
- คำนวณ **BMR (อัตราการเผาผลาญพื้นฐาน)** ด้วยสูตร Mifflin-St Jeor
- คำนวณ **TDEE (Total Daily Energy Expenditure)** และเป้าหมายแคลอรีที่ร่างกายต้องการต่อวัน

### 2. 🍽️ บันทึกอาหารแต่ละมื้อ (เช้า, กลางวัน, เย็น, ของว่าง)
- กำหนดสัดส่วนสารอาหารในแต่ละมื้อเป็น **เปอร์เซ็นต์ (%)**:
  - 🍚 **แป้ง / คาร์โบไฮเดรต (Carbs)**
  - 🍗 **โปรตีน (Protein)**
  - 🥦 **ไฟเบอร์ / ผักผลไม้ (Fiber)**
- มีแถบสไลเดอร์ปรับค่าได้ลื่นไหล พร้อมระบบตรวจผลรวม 100%
- ปุ่มลัด **"สัดส่วนจาน 2:1:1"** (ไฟเบอร์ 50% : แป้ง 25% : โปรตีน 25%) ตามคำแนะนำของกรมอนามัย
- คำนวณแคลอรีและกรัมของแต่ละสารอาหารโดยอัตโนมัติ
- เมนูอาหารไทยยอดนิยมให้เลือกด่วน (เช่น ข้าวกะเพราอกไก่, ข้าวมันไก่, สุกี้น้ำ, สลัดอกไก่ ฯลฯ)

### 3. 📊 สรุปและเปรียบเทียบสมดุลพลังงาน (Calorie Balance Evaluation)
- รวมพลังงานที่ได้รับตลอดวัน เปรียบเทียบกับเกณฑ์ความต้องการ (TDEE)
- วิเคราะห์สถานะทันที:
  - 🔥 **เกินเกณฑ์ (Calorie Surplus)**: ได้รับพลังงานเกิน
  - ⚡ **ขาดเกณฑ์ (Calorie Deficit)**: ได้รับพลังงานยังไม่พอ
  - 🎯 **พอดีเกณฑ์ (Balanced)**: สมดุลตามเกณฑ์สุขภาพ (±50 kcal)
- แสดงแถบสัดส่วนสารอาหารรวมทั้งวัน (% แป้ง, โปรตีน, ไฟเบอร์)

### 4. 🎡 วงล้อสุ่มการออกกำลังกาย (Workout Roulette Wheel) [กรณีพลังงานเกิน]
- วงล้อหมุนแบบ Interactive Canvas พร้อมแอนิเมชันการหมุนและเอฟเฟกต์เสียง
- คำนวณ **ระยะเวลาที่ต้องออกกำลังกายจริง (นาที)** เพื่อเผาผลาญแคลอรีส่วนเกินให้หมดพอดี โดยอิงตามน้ำหนักตัวและค่าความหนัก (METs) ของกิจกรรม:
  - 🪢 กระโดดเชือก (Jump Rope - MET 11.0)
  - 🏃 วิ่งจ๊อกกิ้ง (Jogging - MET 8.5)
  - 🔥 HIIT & บอดี้เวท (MET 9.5)
  - 🚴 ปั่นจักรยานเร็ว (MET 7.5)
  - 💃 เต้นแอโรบิก / ซุมบ้า (MET 6.5)
  - 🏊 ว่ายน้ำ (MET 7.0)
  - 🧗 ขึ้นบันได / เดินชัน (MET 8.0)
  - 🥊 ชกมวย / ชาโดว์บ็อกซิ่ง (MET 8.5)
- **นาฬิกาจับเวลาในตัว (Workout Timer)**: นับถอยหลังตามนาทีที่คำนวณได้ พร้อมปุ่มเริ่ม/พัก/รีเซ็ต และเสียงแจ้งเตือนเมื่อเสร็จสิ้น

### 5. 🥗 ระบบแนะนำอาหารเพื่อสุขภาพ (Smart Nutrition Recommender) [กรณีพลังงานขาด]
- คำนวณแคลอรีส่วนที่ยังขาด
- วิเคราะห์สารอาหารที่ได้รับน้อยในวันนั้น (เช่น โปรตีนยังต่ำ หรือไฟเบอร์ยังน้อย)
- แนะนำเมนูของว่างและอาหารเพื่อสุขภาพที่ช่วยเติมเต็มพลังงานให้พอดี
- ปุ่ม **"+ เติมลงในมื้อของว่าง"** เพิ่มอาหารเข้าสู่ระบบและคำนวณใหม่ได้ทันทีในคลิกเดียว

### 6. 💾 บันทึกข้อมูลอัตโนมัติ (LocalStorage)
- บันทึกข้อมูลโปรไฟล์และมื้ออาหารไว้ในเครื่องโดยอัตโนมัติ ข้อมูลไม่หายเมื่อรีเฟรชหน้าเว็บ
- ปุ่ม **"ล้างมื้ออาหารวันนี้"** สำหรับเริ่มบันทึกวันใหม่อย่างสะดวก
